# LaserClash Landing Template

Reusable, fully-customizable single-product landing page sections for Shopify (OS 2.0).
Original design — no copied copy or assets. Self-contained sections (inline CSS/JS, Google Fonts: Barlow + DM Sans).

## Sections
- `sections/lc-hero.liquid` — Hero + image gallery + color selector + bundle selector + add-to-cart + trust badges. All text/colors/bundles editable in the theme editor.

## How to reuse on a new store
1. Add these section files to the store's theme.
2. Create a product template (see `templates/`) that uses `lc-hero`.
3. Customize text, colors, images, bundles in the Shopify theme editor.

Design tokens: bg #FFFFFF · ink #10204A · accent blue #1742A2 · CTA neon #BFFF0F · card #F3F7FF
